# Memory hygiene checklist

- **Duplicates**: two memories stating the same fact, or one fact split across several memories.
- **Stale**: relative dates ("next week"), finished projects still described as ongoing, tools or files that no longer exist.
- **Wrong type**: a preference saved as `project`, a pointer saved as `user`, etc.
- **Weak descriptions**: a description that wouldn't help decide relevance during recall.
- **Missing why**: `feedback` and `project` memories without **Why:** / **How to apply:** lines.
- **Scope**: global memories that only apply to one project, or the reverse.
- **Broken links**: [[links]] to memories that don't exist and aren't worth writing.
